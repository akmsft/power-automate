# power-automate
This repository contains a collection of tips, best-practices, pre-built solutions, etc. for Power Automate development.

## Tools

### Power Automate Expression Formatter

A free, browser-based tool for formatting, folding, and understanding Power Automate cloud-flow expressions. Runs locally in your browser, with no installation required.

- [Read the guide and see the screenshot](tools/expression-formatter/README.md)
- [Try it online](https://aka.ms/pa-expression-formatter)
- [Download the HTML file](https://aka.ms/pa-expression-formatter-download)

The formatter is a community-built pilot, not an official Microsoft product. Its MIT license applies only to the formatter folder, not the existing solution packages in this repository.
