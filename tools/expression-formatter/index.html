Help & reference

        
      

      

        
        
        
        
      

        

          

            Enter & edit
            

              
Paste a single-line or multiline expression into the left editor. Edit it normally; formatting does not change your input.

              
Editing clears previous results and warnings. Format again when ready.

            

          

          

            Highlights & function hints
            

              
Place the cursor inside a function to highlight its name in blue and show its hint. You can also select a function name to read its hint. Selecting text or leaving the editor clears the blue function highlight.

              
Place the cursor immediately before ( or ) to highlight its matching partner.

              
Red marks indicate errors. Amber underlines indicate warnings. Select an underlined function to inspect its issue.

            

          

        

        

          

            Format & fold
            

              
Select Format expression or press Ctrl+Enter. Your input stays unchanged.

              
Use - / + to fold individual groups, or Expand all / Collapse all.

            

          

          

            Line numbers
            

              
Input numbers count actual line breaks, not wrapped rows. Result numbers refer to the full formatted expression and stay fixed when groups collapse.

              
Error and warning locations refer to the left input. The two editors need not have matching line numbers.

            

          

          

            Errors & warnings
            

              
Select an underlined function or the issue badge. Keyboard: Alt+ArrowDown with the cursor on an affected function.

              
Previous / Next clears the outline and moves to the next function, scrolling only the input if needed.

              
Errors block formatting, explanations, and copying, and appear in the right-side error panel. Fix the input and format again.

              
Unknown functions produce warnings, not errors: they may be valid but missing from this tool's catalog. Warnings allow formatting and copying.

              
Dismiss the overlay with Escape, Close, or a click outside.

            

          

          

            Moving the issue overlay
            

              
Drag its header to move it. Keyboard: focus the header and use arrow keys; hold Shift for finer movement.

              
The position stays for the current issue. Previous/Next, another function, or reopening restores its position beneath the function.

              
The default overlay stays beneath its function on the page. It can scroll out of view without closing; scroll back to see it again. A manually moved overlay stays at your chosen position in the browser window.

            

          

          

            Explain expression
            

              
Select Explain expression for Summary, Steps, and Notes. Use the result-header switch to return to formatted code.

              
Labels such as "formatted text" are reading aids, not new flow variables. Review unsupported parts and caveats in Notes.

            

          

        

        

          

            Choose a copy format
            

              
Copy formatted keeps indentation and line breaks.

              
Copy single line removes layout spacing and keeps one space after commas.

              
Both include collapsed sections, exclude line numbers, and preserve quoted text.

            

          

          

            If copying is unavailable
            

              
A literal line break inside a quoted string disables single-line copying. Use Copy formatted to preserve it.

              
If clipboard access is blocked, copy the selected expression under Plain text manually.

            

          

        

        

          

            What is checked
            

              
Structural errors: unmatched parentheses, brackets, and quotation marks.

              
Argument errors: incorrect counts for cataloged functions and empty argument slots. Optional and variable-length argument lists are supported.

              
Warnings: functions outside the local catalog cannot be verified. They are not automatically invalid.

            

          

          

            What is not validated
            

              
Unknown functions, argument types or values, array contents, and runtime behavior. Hints do not cover the entire function reference.

              
Explanations use local rules, not a language model. They do not execute your expression or infer business context.

              
No warnings is not a guarantee of success. Review the expression before using it in a flow.

            

          

          

            Light & dark theme
            

              
Use the sun/moon switch in the header to toggle Fluent Graphite on or off. Light is the default; the tool does not follow your Windows theme.

              
Your last choice is remembered in this browser for 30 days from each toggle. Only the theme and its expiry are saved, never your expression.

              
Browser privacy settings or moving the file may prevent the choice from being retained. If storage is blocked, switching still works for the current page.

            

          

          

            Privacy & ownership
            

              
Your expression stays in this browser and is not uploaded. Microsoft reference links open external documentation only when selected.
